Part of the **ml5.js 1.0** redesign and research effort at NYU ITP, focused on making client-side machine learning approachable for artists, students, and creative coders directly in the browser.

## Interactive Code Runner & Model Reference

Rather than requiring learners to switch between static API reference pages and an external editor, the updated documentation embeds a live **p5.js + ml5.js code editor and webcam canvas** directly inside each model guide (`BodyPose`, `HandPose`, `FaceMesh`, `ImageClassifier`, and `NeuralNetwork`).

### Key Improvements

- **Live In-Page Execution**: Visitors can inspect, edit, and run `ml5.faceMesh`, `ml5.handPose`, and `ml5.bodyPose` sketches inline with real-time webcam feedback.
- **Unified v1.0 API Patterns**: Standardized lifecycle methods (`preload()`, `detectStart()`, `detectStop()`) across all pretrained TensorFlow.js models.
- **Zero-Install Onboarding**: Quickstart templates link directly to the p5.js Web Editor with preconfigured CDN script tags (`ml5.min.js`), bridging reference examples to full projects like [[look-at-you|Look At You!!!]] and [[webcam-nn|Webcam Handpose Neural Network]].

```javascript
let facemesh;
let video;
let faces = [];

function preload() {
  facemesh = ml5.faceMesh();
}

function setup() {
  createCanvas(640, 480);
  video = createCapture(VIDEO);
  video.size(640, 480);
  video.hide();
  facemesh.detectStart(video, gotFaces);
}

function gotFaces(results) {
  faces = results;
}
```
