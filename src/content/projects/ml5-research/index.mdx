Conducted during Daniel Shiffman's **ml5.js Research Studio** at NYU ITP (Spring 2024), this research project focused on redesigning the **ml5.js 1.0** website and embedding a live, interactive code editor directly inside the reference documentation so beginners can experiment with browser-based machine learning models without context-switching.

- **Research Proposal**: [ml5.js Website Functionality Enhancement and Examples with Built-in Editor](https://github.com/ml5js/research-studio-s24/blob/main/projects/alanren.md)
- **Prototypes**: [`ml5-website-v02-docsify`](https://github.com/alanvww/ml5-website-v02-docsify) · [`ml5-website-v02-gatsby`](https://github.com/alanvww/ml5-website-v02-gatsby)

## Research Objectives

1. **Centralize Learning Resources**: Unify API reference pages, video tutorials, and runnable examples into a single cohesive documentation flow.
2. **Embed an In-Page Live Code Editor**: Allow learners to inspect, modify, and execute `p5.js` + `ml5.js` sketches (`FaceMesh`, `HandPose`, `BodyPose`, `ImageClassifier`, `NeuralNetwork`) with live webcam feedback directly inside the docs.
3. **Optimize Performance & Cross-Origin Execution**: Evaluate single-page documentation architectures (Next.js, Gatsby/React, Vite, and Docsify) while resolving `iframe` HTTPS and camera permission constraints for embedded sketches.

## Prototyping the In-Page Code Runner

Early iterations tested a **CodeMirror** + **Next.js** proof-of-concept and evaluated sandboxing strategies for running live webcam sketches inside documentation pages. Resolving `iframe` camera/microphone permissions over HTTPS enabled seamless inline execution alongside each model's syntax breakdown, which directly informed later work on the [[help-page|p5.js Built-In Help Page]] during Google Summer of Code.

```javascript
let facemesh;
let video;
let faces = [];

function preload() {
  facemesh = ml5.faceMesh();
}

function setup() {
  createCanvas(640, 480);
  video = createCapture(VIDEO);
  video.size(640, 480);
  video.hide();
  facemesh.detectStart(video, gotFaces);
}

function gotFaces(results) {
  faces = results;
}
```
