Built for Yining Shi's *Machine Learning for the Web* course at NYU ITP (Spring 2024), **Water Break Timer** pairs a custom **Google Teachable Machine** image classifier (`ml5.imageClassifier`) with the browser's **Web Notifications API** to enforce hydration breaks during long coding sessions.

## Interaction Loop

Instead of a passive countdown timer that can be dismissed with a click, the sketch watches the live webcam feed (`320×240`) to verify whether you actually picked up a cup:

1. **Idle Countdown (`Just me :(`)**: While sitting at the desk without a mug in frame, the 20-minute countdown timer (`timerDuration = 20 * 60 * 1000`, shortened to 5 seconds for demo recording) ticks down at the bottom of the canvas.
2. **Desktop Alert (`Time's up!`)**: When `millis() - startTime > timerDuration`, the status bar turns bright red (`background(255, 0, 0)`) and dispatches a native OS notification via `new Notification("Water Break Timer", { body: "Time's up! Take a water break." })`.
3. **Visual Verification (`Mug`)**: Raising a mug into frame switches the top classification result (`results[0].label`) to `"Mug"`, immediately calling `resetTimer()` to restart the countdown.

## Implementation

```javascript
let classifier;
let imageModelURL = "https://teachablemachine.withgoogle.com/models/UySicD1il/";
let timerDuration = 20 * 60 * 1000; // 20 minutes in milliseconds

function preload() {
  classifier = ml5.imageClassifier(imageModelURL + "model.json");
}

function gotResult(error, results) {
  if (error) return console.error(error);
  label = results[0].label;

  if (label === "Mug") {
    resetTimer();
  }
  classifyVideo();
}

function showNotification() {
  if ("Notification" in window && Notification.permission === "granted") {
    new Notification("Water Break Timer", {
      body: "Time's up! Take a water break.",
    });
  }
}
```
