An interactive machine learning experiment built at NYU ITP that chains **ml5.js HandPose** skeletal landmark extraction into a custom client-side **ml5.neuralNetwork** classifier—allowing users to train directional hand gestures in the browser and immediately use them to paint with a live webcam feed.

## In-Browser Data Collection & Training

Rather than writing brittle coordinate thresholds for finger angles, the sketch uses the 21 3D hand keypoints output by `ml5.handPose` as feature vectors for a custom 4-class neural network (`Up`, `Down`, `Left`, `Right`):

1. **Sample Capture**: Buttons below the canvas (`Add Hand Point Up Data`, `Down`, `Left`, `Right`) record labeled snapshots of the current hand skeleton directly in the browser.
2. **Client-Side Training**: Clicking `Train and Save Model` normalizes the keypoint inputs, runs training epochs via `ml5.neuralNetwork`, and exports the trained weights for real-time inference.

## Gesture-Driven Slit-Scan Canvas

Once trained, continuous classification results (`Up`, `Down`, `Left`, `Right`) translate the live webcam viewport across the p5.js canvas without clearing previous frames—generating layered slit-scan trails as you point in different directions.
