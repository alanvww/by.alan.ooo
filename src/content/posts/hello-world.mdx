# Hello World: Getting Started with Next.js 15

Next.js 15 introduces several exciting new features that push the boundaries of web development. In this post, I'll walk through some of the most significant improvements and show you how to leverage them in your projects.

## Server Components: A New Paradigm

React Server Components represent a paradigm shift in how we build React applications. With Next.js 15, they're now the default approach.

```jsx
// This is a Server Component
export default function Page() {
	return (
		<div>
			<h1>Hello, Server Component!</h1>
		</div>
	);
}
```

Server Components offer several advantages:

- **Reduced bundle size** - Server Components aren't included in the JavaScript bundle sent to the client
- **Direct backend access** - Server Components can directly access backend resources
- **Improved initial page load** - Content can be rendered on the server for faster first load

## Turbopack: Lightning-Fast Builds

Turbopack is a Rust-based successor to Webpack, designed for incredible speed. Next.js 15 includes an improved version with better compatibility and performance.

To enable Turbopack in development:

```bash
npm run dev -- --turbo
```

Or in your package.json:

```json
{
	"scripts": {
		"dev": "next dev --turbo"
	}
}
```

The performance improvements are substantial, especially for larger applications:

| Metric      | Webpack | Turbopack |
| ----------- | ------- | --------- |
| Cold start  | 35s     | 1.8s      |
| File update | 180ms   | 20ms      |

## Improved Image Optimization

Next.js 15 enhances the `Image` component with better performance and quality controls:

```jsx
import Image from 'next/image';

export default function Hero() {
	return (
		<Image
			src="/hero.jpg"
			width={1200}
			height={600}
			priority
			quality={90}
			alt="Hero image"
		/>
	);
}
```

### Code Examples

Here's a more complex example showing how to create a custom hook:

```typescript
import { useState, useEffect } from 'react';

interface UseLocalStorageOptions<T> {
  defaultValue?: T;
  serialize?: (value: T) => string;
  deserialize?: (value: string) => T;
}

export function useLocalStorage<T>(
  key: string,
  options: UseLocalStorageOptions<T> = {}
): [T | undefined, (value: T) => void] {
  const {
    defaultValue,
    serialize = JSON.stringify,
    deserialize = JSON.parse,
  } = options;

  const [value, setValue] = useState<T | undefined>(() => {
    if (typeof window === 'undefined') return defaultValue;
    
    try {
      const item = window.localStorage.getItem(key);
      return item ? deserialize(item) : defaultValue;
    } catch (error) {
      console.warn(`Error reading localStorage key "${key}":`, error);
      return defaultValue;
    }
  });

  useEffect(() => {
    if (typeof window === 'undefined') return;
    
    try {
      if (value === undefined) {
        window.localStorage.removeItem(key);
      } else {
        window.localStorage.setItem(key, serialize(value));
      }
    } catch (error) {
      console.warn(`Error setting localStorage key "${key}":`, error);
    }
  }, [key, value, serialize]);

  return [value, setValue];
}
```

## Getting Started with Next.js 15

Creating a new Next.js 15 project is straightforward:

1. Use create-next-app:

```bash
npx create-next-app@latest my-app
```

2. Start the development server:

```bash
cd my-app
npm run dev
```

3. Open http://localhost:3000 to see your application.

## Project Structure

Here's a recommended project structure for Next.js 15 applications:

```
my-app/
├── src/
│   ├── app/           # App Router pages
│   ├── components/    # Reusable components
│   ├── lib/          # Utility functions
│   └── content/      # MDX content files
├── public/            # Static assets
├── package.json
└── next.config.ts
```
